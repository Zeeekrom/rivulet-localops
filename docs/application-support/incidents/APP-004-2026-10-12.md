## Additional local container preflight finding

The v0.8.0 release preflight also reproduced a real Docker Desktop startup failure outside the Rivulet application.
Desktop 4.91.0 could not rotate a stale zero-byte `sailor-ingest` AF_UNIX runtime socket. Stopping Docker did not make
the socket movable through the Windows filesystem. The check stopped without factory reset, WSL-wide shutdown or data
deletion. Therefore this report does **not** claim a v0.8.0 local container run; `docker-preflight.json` records the
sanitised observation and the hosted Linux image build remains mandatory.
