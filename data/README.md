# Data provenance

| Component | Status | Source and permitted use in this prototype |
|---|---|---|
| Litter-bin locations and attributes | Real public asset data | City of Hobart ArcGIS open-data service; retrieved by `scripts/fetch_hobart_assets.py` |
| Monthly request-for-service counts | Real public aggregate reference data | Townsville City Council data.gov.au CSV; retrieved by `scripts/fetch_townsville_rfs.py`; not Hobart demand and not individual requests |
| Individual resident request text | Synthetic or manually authored evaluation examples | No real resident records are included |
| Triage category and priority labels | Project policy baseline | Demonstration decisions, not adopted council policy |
| Submission Gate policy | Synthetic, versioned policy pack | `policies/waste_litter_demo_v0.1.0.json`; approved only for this portfolio demonstration and not adopted council policy |
| Agent capability registry | Synthetic control configuration | `agents/case_agent_v0.1.0.json`; demo identity, owner, provider binding, grants and allowlists only—not an external identity or signed policy system |
| Decision, review and provider-control events | Fixed-seed synthetic operational data | Versioned D6 JSONL generated by `scripts/generate_synthetic_ledger.py`; never presented as council operational history |
| Response times, staffing and outcomes | Synthetic demonstration only | D6 includes designed review timing and outcomes to exercise the mart; these must never be presented as observed Hobart performance |

The Hobart retrieval script requests `outSR=4326`; this avoids silently treating the source service's projected coordinates as latitude/longitude. Each source has a machine-readable contract under `source_manifests/` with retrieval time, hash, grain, schema and limitations. `quality/source_quality.json` records automated D1/D2 checks. The versioned mart in `mart/v1/csv/` keeps real public reference facts separate from synthetic operational facts.
