# Synthetic samples

Everything in this folder is synthetic and generated from the private source for illustration. None of it is
resident data, council policy or council performance.

| File | What it shows |
|---|---|
| `demo-scenarios.json` | The six live-demo scenarios: request text, diagnosis, every Gate rule with its outcome, agent tool receipts |
| `policy-pack-v0.2.0.json` | The demonstration policy pack the Gate enforces, including the input-integrity settings behind `POL-INPUT-001` |
| `ledger-events-sample.json` | The first events of the fixed-seed synthetic ledger, showing the hash chain fields |
| `adversarial-examples.json` | Eight adversarial cases and how the Gate treated them under policy 0.1.0 and 0.2.0 |
