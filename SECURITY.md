# Security and Responsible Use

Rivulet LocalOps is a portfolio prototype. Please do not enter real resident, employee or other personal information anywhere in it: every request it handles is meant to be synthetic, and the live site keeps nothing you write.

This repository holds the write-up, the films, the poster and the cards only; the source code is private.

## Reporting a problem

If you find a security issue in the replay, the live site or the public demo, please [message me on LinkedIn](https://www.linkedin.com/in/evan-h-165976301/) instead of opening a public issue, and please do not test them beyond normal use.

## What it is not

It is not a production system. Staff sign-in and roles, an independently protected audit store and connectors to council systems are not built; see [What it can and can't do today](README.md#what-it-can-and-cant-do-today).
